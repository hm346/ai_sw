# Users Chat AI 全栈项目 — 学习笔记

---

## 一、项目架构：前后端分离 + 模块化

```
项目根目录
├── backend/          # 后端 — Node.js + json-server
│   ├── package.json
│   └── db.json       # JSON 文件作为数据存储
└── frontend/         # 前端 — HTML + CSS + JS
    ├── index.html
    ├── style.css
    └── app.js
```

协作形式：**前后端分离、古法编程（不用框架，从基础做起）**

---

## 二、模块化原则

| 层级 | 规则 |
|------|------|
| 函数 | 一个函数只做一件事 |
| 文件 | 一个文件只写一个类 / 模块 |
| 文件夹 | 一个文件夹只负责一个功能模块 |

**优势**：好维护、高质量、可读性强、简单可靠

## 三、JavaScript 的定位

JS 是一门"全领域"语言：**前端、后端、AI、嵌入式** 都能做。

## 四、后端初始化流程

```bash
npm init -y          # 生成 package.json（项目描述文件）
npm i json-server    # 安装 json-server（快速搭建 RESTful API）
```

- `npm` = Node Package Manager（Node 包管理器）
- `package.json` = 项目的身份证，记录依赖和脚本

## 六、RESTful API 设计

### URL 设计范式

```
协议://域名:端口/资源
https://localhost:3000/users
https://localhost:3000/users/:id
https://localhost:3000/posts
https://localhost:3000/posts/:id
```

### HTTP 动词 → CRUD 映射

| 动词 | 操作 | 示例 |
|------|------|------|
| **GET** | Read（读取） | `GET /posts/:id` |
| **POST** | Create（创建） | `POST /posts` |
| **PUT/PATCH** | Update（更新） | `PUT /posts/:id` |
| **DELETE** | Delete（删除） | `DELETE /posts/:id` |

RESTful 是 Web 开发的根基，URL 设计要面向资源而非动作。

### 7.1 HTML 核心概念

**盒子模型**
- 块级元素具有宽高能力，PC 端常用固定宽度 + 左右留白（`container`）

**语义化标签**
- 推荐结构：`div.container > nav + main + footer`
- 拒绝 `<div>` 满天飞：导航用 `<nav>`，主体用 `<main>`，底部用 `<footer>`
- 好处：
  - 可读性好，便于维护
  - **SEO 友好** — 百度/谷歌爬虫通过分析 DOM 结构理解页面内容

**SEO** = 搜索引擎优化，爬虫爬取网页 → 分析 DOM 结构 → 建立索引

---

### 7.2 DOM（Document Object Model）

**Document 是什么？**
- HTML 文档本质上是一个文本文件
- `Content-Type: text/html` → 浏览器识别为 HTML
- `<!DOCTYPE html>` 标记这是 HTML5 文档

**DOM 树结构**

```
html（根节点）
└── body（可视区）
    ├── header
    ├── .container
    │   ├── nav
    │   ├── main
    │   └── footer
    └── ...
```

**Object Model 的含义**
- HTML 文本经过浏览器 HTML Parser（C++ 实现）解析后，在内存中构建一棵树
- 这棵树暴露为全局的 `document` 对象
- 通过 `document` 对象可以**动态操作 HTML** → 这就是 DOM 编程

**DOM 查询性能**

```js
document.querySelector('#id')    // 最快 — ID 唯一，有索引
document.querySelector('.class') // 次之
document.querySelector('tag')    // 最慢 — 遍历所有同标签元素
```
